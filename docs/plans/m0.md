## 交付与非目标

交付真实 Go／SMB／tsnet 的可安装 Android probe APK（内含 Go AAR）、自动构建 Actions、host 注入 `net.Conn` 的受控 SMB no-replace／读回实验，以及 Dora Android **物理设备**中 App 内 tsnet 到受控 SMB 的至少一次完整内容 SHA-256 读回。取消或进程终止不得误报完成，已完成的本地副本必须保留以便对账。Dora 必须使用本会话新 lease，并在 `finally` 中清理和释放。

## 受控网络、数据与凭据

C1 必须记录服务 owner、服务器版本、隔离测试共享、限域短期凭据、配额、允许流量、撤销和自有文件清理方式。host 直连只在受控私网进行；Dora 不默认与 host／家庭 NAS 同网。优先让授权测试服务器加入测试 Tailnet，由 App 内 tsnet 连接 TCP 445；不为验收无限制暴露公网 445，不以系统 VPN 或桌面传输替代 App 内 tsnet。

M0 硬 gate 要求 host 注入 `net.Conn` 的 SMB 路径和 Dora App 内 tsnet 路径各自有连接与内容结果；Dora V04 至少一次完整文件上传／flush／读回 SHA-256 一致。Dora 直接 SMB、第二网络路径和>4 GiB 非稀疏压力属于附加证据，未运行必须写 `NOT_RUN`，不能改写硬 gate。

## Dora session 隔离与清理

按上级 AGENTS 使用 `auth status`，显式 `--os android --device-type physical` 查询 idle＋online 候选。占用后同时 `device get` 和 occupied list，保存本会话 serial／session ID／endpoint。每次连接、ADB、续租或释放前重新 `get` 并核对 session ID；不匹配／缺失即停止操作。

连接后确认 OS／API／ABI、网络、安装和启动。自动化用 `trap`／`finally`，停止续租进程后只释放仍匹配的本会话 lease，并确认它从 occupied 列表消失。租约结束前撤销测试节点／账号并删除本任务素材／状态；不接管旧会话或他人设备。该清理是安全条件，不转化为协议通过。

## 独立 review、停止与用户 gate

本阶段只做一次独立 plan review，检查硬 gate、受控服务前提、host／Dora 路径、凭据最小范围、no-replace、真实 APK、session 隔离和停止条件。实现完成后由非作者进行最终 integrated/device review，重新核对最终 SHA 与证据；旧范围的 PASS 不覆盖本次收缩后的 head。

构建／桥接不成立、Dora 到服务不可达、无有效物理 lease、无法 no-replace、或取消／终止误报完成时，相关硬 gate `FAIL`／`BLOCKED`，不得用附加结果替代。附加项低概率或条件不满足时如实记 `OPTIONAL`／`CONDITIONAL`／`NOT_RUN`。不得扩展公网访问、冒用旧 lease 或降低内容校验。

只有 M0-V01–V05 通过并完成独立 integrated/device review，才可报告协议结果“**M0 受控协议实验通过**”；M0-V09 是每次设备实验的强制安全收尾，若失败则该设备运行记为 `BLOCKED`／cleanup failure、停止后续设备操作，但不改变 V01–V05 的协议 gate，也不使 V06–V08 或 M0-UI 变成硬 gate。同时列清 M0-V06–V08、M0-UI 及 Pocket／Pixel／iPhone／真实飞牛的未测范围。提交 APK、证据、未决项和 M1 条件给用户；用户明确批准 M1 后才能执行 Pocket 完整链路或进入下一 milestone。
