# Ferry

Bring camera media to your own storage.

Ferry 是一个规划中的移动应用：将相机原始素材导入手机，并根据规则上传到用户自己的存储。

当前阶段只提供公开规划审阅，尚无可运行 App 或 APK。首期方向是 Android／Pixel 6 Pro、DJI Osmo Pocket 3 USB／OTG、飞牛 SMB 和内嵌 tsnet；iOS／iPhone 17 Pro USB-C 紧随其后。

完整方案、协作规则和示例配置将通过规划 PR 提交审阅。后续应用实现须等待用户明确批准相应里程碑。

许可证已由用户选定 Apache-2.0；标准许可证文件将随规划 PR 提供。
